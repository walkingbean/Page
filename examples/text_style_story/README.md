# 文本、样式与交互示例 — 0.4.0

将整个目录复制到可写位置，选择它为 Content Folder，打开 conversation.dtl，按 F5 预览。

点击或 Enter/Space 推进；名字输入框用 Enter 确认。WaitInput 需要一次新的推进输入，选择按钮需要点击。Auto 和 Skip 是当前预览开关，Esc/F6 关闭。角色样式、原生富文本效果、随机文本、分段追加、字体、内嵌 PNG、设置、等待、清除和变量分支均来自原生文件。

在 Layouts 中编辑 Base/Warm/Cool 及布局层；Settings 编辑文本配置；Character 页编辑专属样式和前后缀；时间线选中行后点击对应事件属性入口。

字体采用 Noto Sans CJK（SIL OFL 1.1）；PNG 来自指定 Dialogic 示例素材，许可见发布包 third_party/。预览不写入运行姓名或 Setting 值。媒体声音和宿主扩展功能在后续版本完成。
