# PAGE Editor 0.6.0 · 术语与多语言

将本目录复制到可写位置，选择为 Content Folder，打开 story.dtl，再 Play。预览顶部可选择 zh_CN、en、ja；切换会从头播放。

- 将鼠标移到“月球/明月”、“Moon/Luna”或“月/お月様”上，查看原生术语弹窗。
- Glossary 编辑 glossary.tres 的条目和别名，Save glossary 保存。
- Translate 可查看三份 CSV。修改原文后 Update CSV files；修改译文后 Save CSV，再 Collect translations。
- 角色的显示名和昵称也包含三种语言。文件身份 guide.dch 保持固定。
- 转移到目标游戏时，需安装固定 Dialogic 2.0-alpha-20 并配置原生 Dialogic autoload。此文件夹是内容示例，不包含插件或游戏启动场景。

CSV、.translation、.tres、.dtl、.dch 与 project.godot 均使用固定版本的原生格式。这里的文字和术语为演示内容。
