# PAGE Editor

**独立创作对话，输出原生 Dialogic 内容。**

PAGE Editor 是面向叙事内容创作者的桌面编辑器。Windows 和 Linux 发布程序可直接运行，在一个界面中编写时间线、管理角色和变量，并预览对话。无需打开 Godot 编辑器运行 PAGE Editor。

项目面向 Godot 4.7.1 与 Dialogic 2.0-alpha-20，使用该版本的原生时间线、角色和变量配置，便于把创作内容交给目标 Godot 工程。

## 从内容开始

- 编写旁白和角色台词，查看源行诊断。
- 管理基础角色、默认立绘及基本进退场。
- 使用标量变量和表达式计算对话内容。
- 在独立窗口中播放、停止和重启对话。

项目仍在开发。最终目标是覆盖固定版本 Dialogic 的全部创作、资源管理、运行预览和原生输出能力；当前已实现范围以版本使用说明和发布说明为准。
