### 1.1 测试数据与执行条件

- **F-STORY**：随包 `examples/character_story/` 的独立可写副本，含 jane、antonio、PNG 和时间线；本版变量示例另建独立副本。
- **F-TEXT**：含中英文旁白、独立注释、转义冒号、两物理行续行、转义井号与行内井号。下方文本预览为 5 条 Text，注释不播放。

- **F-PNG**：普通 PNG、同名不同内容 PNG、伪 PNG、损坏及各项边界图；记录真实尺寸、总像素和字节数。
- **F-SCAN**：普通根、重复标识、20000 项及超限、深度 64 及超限、不可读子目录和链接。扫描项包含目录项。
- **F-SOURCE**：全新解压本版 Source 的临时副本；匹配 Godot 4.7.1 和 4.7.1.stable 导出模板，Dialogic 2.0-alpha-20；品牌试验不能改正式交付文件。
- **F-REF**：用户已验证可用的指定 Godot/Dialogic 参考工程副本，用于正反向互通与语义比较。
- **F-VAR**：普通空内容根；有完整 project.godot 的根；缺变量键/空字典/其他类型混合字典；有注释和其他设置的 LF/CRLF 配置；两个同名变量但值不同的内容根；错误与只读配置。
- **F-PLATFORM**：普通用户桌面环境及隔离文件副本；记录系统、显示后端、字体/输入法和实际工具版本。权限、锁定、目录移动、链接、外部改写只操作测试副本。
- 日志/截图记录真实行为；文件无损以字节或哈希比较。用例列出的每种数据分别留记录，不用单一样本代表全部边界。时间和内存观察可留证据，不设置未经确认的性能门槛。


精确边界：

| 对象 | 约定 |
|---|---|---|
| .dtl / .dch | 4,194,304 字节（4 MiB），包含 BOM 和实际换行编码 |
| PNG 文件 | 不超过 33,554,432 字节（32 MiB） |
| PNG 单边 | 1—8192 像素 |
| PNG 总像素 | 不超过 16,777,216；4096×4096 为边界，4097×4096 超限；仍需同时满足其他约束 |
| SVG | 不超过 2,097,152 字节（2 MiB），真实可解析 SVG |
| 扫描 | 不超过 20000 项；根深度 0，进入大于 64 的目录报告不完整 |

本版 docs/README 与发布说明中的这些限制应使用准确数值；不能将 16,777,216 简写为导致边界误判的“1600 万”。
