# PAGE Editor 0.1.0 发布说明

Godot：4.7.1.stable.official.a13da4feb；Dialogic：2.0-alpha-20。

本版提供嵌套 if / elif / else、原生条件文本与对应属性编辑。保存、重开、撤销重做、物理源行列诊断以及原生预览覆盖变量与条件的组合。基础创作、角色、默认立绘、目录、变量与标量表达式保持可用。

## 功能与范围

- Condition 表单支持当前缩进层级的创建和编辑，保留正文，最多 64 层。
- Conditional Text 表单创建或编辑 `[if 条件 真文本/假文本]`；先选分支，再展开变量，按原生规则处理空白和全局替换。
- 语法与引用检查覆盖未命中路径；运算只检查实际命中路径。停止与重启不写回保存初值。
- `examples/nested_story` 展示嵌套、赋值和条件文本组合；修改 ready/score 后保存并重启查看各条路径。
- 用户维护的根 README 保持原字节；使用说明在 docs/README.md；品牌和 SVG 配置在 docs/BUILD.md。

Tab 或统一 1—32 空格单位，不能跳层或混用。原生 EOF 可能生成额外内部 EndBranch，不向 .dtl 写入显式结束标记。行内条件不再嵌套；真文本内 `/` 是原生分隔符，细节见使用说明。BBCode、随机文本、变量文件夹、数组/字典、函数及宿主扩展尚未实现；完整 Dialogic 目标不变。

下一版本为 **0.2.0：条件选项、分支、跳转与跨时间线流程**，需要用户另行确认开始写代码。
