# PAGE Editor 0.6.0 发布说明

日期：2026-10-27（UTC+8）。固定 Godot 4.7.1 Standard / Dialogic 2.0-alpha-20，基于正式 0.5.0 Source。本版为「术语与多语言」。

## 本版功能

- Glossary 窗口编辑原生术语资源、名称、别名、说明、附加文字、颜色、启用与大小写选项，以及项目注册顺序。
- Translate 窗口配置原始语言与输出位置，生成和更新原生 CSV，添加语言、编辑、导入、导出与收集原生 `.translation` 文件。
- 为时间线文本、选项、角色及术语维护稳定的原生翻译 ID；更新源文时保留已有译文、其他语言、扩展字段和待复核的旧条目。
- 预览支持切换语言、翻译角色名称与昵称、术语高亮和原生悬浮说明；退出后恢复宿主语言、翻译资源、设置及术语状态。
- 提供 `examples/localization_story` 中文、英文、日文示例。保留既有事件、变量、表达式、条件、流程、角色、立绘、文本样式和媒体状态功能。

根 README 由用户维护并保留原字节。保留原始主场景和主题，不修改固定 Dialogic 插件语义。目标内容根与应用资源根分离。下一功能版本为路线图中的 0.7.0；本次授权仅覆盖 0.6.0。

## 使用与边界

选择内容根，打开 Glossary 编辑并保存术语。在 Translate 中确定原始语言与输出模式，执行 Update CSV files，编辑各语言列后 Save CSV，最后 Collect translations。预览顶部的语言选择会从头重启当前时间线；不同语言的预览存档不能互相加载。

原生 alpha-20 术语条目是 Dictionary，别名映射到原始条目名。原生术语使用正则匹配语义，名称并非自动转义的纯文本搜索。支持范围和安全诊断见 docs/README.md。

CSV 必须保留稳定键；重复键、等价重复语言列、错误引号、NUL 或超过 4 MiB 的文件会被拒绝。收集生成原生 Translation 资源及项目注册。PAGE 预览以内容 CSV 为译文来源，只有已编译 Translation、缺少 CSV 的项目会明确提示。缺失或空译文回退到原始文本。

未知脚本、自定义资源依赖和无法安全解析的术语资源不会被当成可编辑标准数据。译文和术语中的变量、函数、图片及字体继续经过内容边界检查。术语图片等运行资源只在预览会话内重映射，磁盘内容保持原生路径。

写入前检查外部变更和目标路径，多文件操作先准备临时文件与恢复副本；正常提交失败会尝试回滚。这不是跨文件的断电原子事务，真实磁盘满和断电恢复不属于已验证能力。

既有预览存档适配仅服务 PAGE 预览，不承诺目标游戏可直接使用；固定插件未保存的音频精确时刻或半字揭示进度仍不保证。音频测试使用 Dummy 驱动与原生状态观察，不表示已通过物理扬声器听音。

## 异常历史与恢复

本版所有失败、诊断修订和重跑保留在独立 Test_Progress。早期脚本编译、术语解析栈、角色 ID 复制、语言回退与窗口定位问题修正后执行对应重跑；最终状态仅采用源码与程序匹配的记录。原始截图与用于 OCR 的派生图分开保存。固定引擎 release 模板的嵌入式 Popup 关闭错误通过最小工程复现；应用对本版新增下拉菜单使用原生 Popup 并处理桌面坐标，未修改引擎和插件。

固定引擎在本版执行 583 的全新字体导入中打印 `malloc(): corrupted top size` 并以 -11 退出，后续步骤立即停止。相同产品源码的新目录完整重跑 594 通过；全新 Source 导入、双平台导出和打包核对 595 通过。未修改引擎，成功重跑不代表崩溃根因已解决。

另保留测试工具问题及修正记录：样本 JSON 同步遗漏、待观察选择状态提前推进、短自动推进文本的采样时机、动态诊断日志的封包摘要快照，发布检查遗留旧版用例数量，以及导出程序 Restart 按钮 OCR 命中状态文字、窗口标题仍匹配旧版号。这些修正未改变产品代码或已冻结的用例定义；对应验证均重新执行并留证。
