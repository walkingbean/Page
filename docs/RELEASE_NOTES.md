# PAGE Editor 0.0.5 发布说明

Godot：4.7.1.stable.official.a13da4feb（标准版）  
Dialogic：2.0-alpha-20  
平台：Windows x86_64、Linux x86_64

本版新增单层 if / elif / else 条件、对应属性编辑和原生分支预览。最终目标保持为完整覆盖指定 Dialogic 版本的全部功能，输出原生标准内容。

## 功能与使用

- Condition 表单创建和编辑原生条件头，保留正文；取消、撤销重做、只读和过期表单保护。
- 单层 Tab / 一致空格缩进，空分支、分支边界、内部 EndBranch 及物理源行列诊断。
- 按首个命中分支预检与执行；分支内变量赋值影响后续文本和条件。运行值不写回初值，重启恢复已存初值。
- 分支内 Variable、Text、Comment、Character 插入和编辑保留缩进。
- 原有基础创作、角色、立绘、目录、变量、表达式、查找和文件保护继续提供。
- 根宣传 README 保持字节不变；使用说明在 docs/README.md；品牌配置和 SVG 方法在 docs/BUILD.md。

复制 examples/condition_story 到可写位置并选为 Content Folder，打开 conversation.dtl。score 初值 12 / 7 / 2 分别选择高分 / 普通 / 开始路线。

嵌套条件与完整条件文本留待 0.1.0，条件选项、跳转和跨时间线流程留待 0.2.0。条件变量使用 {name}；if/elif 表达式不得为空。原生空格 EOF 可能生成额外内部 EndBranch，本版保持原生行为，不写入显式结束标记。未命中路径仍检查语法和引用，但不执行其运算。完整边界见使用说明。

下一功能版本为 **0.1.0：变量与条件**。本版授权不延伸至下一版。
