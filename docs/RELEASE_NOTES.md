# PAGE Editor 0.0.4 发布说明

Godot：4.7.1.stable.official.a13da4feb（标准版）  
Dialogic：2.0-alpha-20  
平台：Windows x86_64、Linux x86_64

本版增加标量表达式、直接 SET 表达式赋值和文本表达式，可计算变量并在实际对话中显示结果。最终目标仍是覆盖固定版本 Dialogic 的全部功能，输出原生标准内容。

## 功能

- 算术、比较、逻辑、括号、变量传值及字符串连接；按固定引擎语义保留类型与结果。
- Variable 属性窗口增加 Expression 模式，支持插入、加载、编辑、撤销重做和过期表单保护。
- 常量文本 `{1+2}` 无需内容根；变量计算如 `{{score}+1}` 使用已保存内容根。
- 语法、缺失引用、类型错误、除零、非有限结果、容量及文本效果范围检查；诊断映射到物理源行列。
- 原始 Dialogic 顺序执行；开始、重启恢复已存初值，运行值不写回配置或时间线。
- 基础时间线、角色、默认立绘、进退场、目录、查找和文件保护继续可用。
- 使用说明移至 docs/README.md；根 README 创建项目主页初版，后续由用户维护。品牌和 SVG 方法在 docs/BUILD.md。

## 使用与边界

复制 `examples/expression_story/` 到可写目录，选择为 Content Folder，打开 `conversation.dtl`。在 Timeline 的 Variable 表单中选择 Expression。

函数、方法、宿主属性、数组/字典、下标、位运算、字符串格式化、复合赋值与条件分支尚未开放。表达式遵循固定原生引擎的整数除法、整数幂、优先级和非短路逻辑；完整语法、精度与容量边界见 [使用说明](README.md)。预览需要至少一条可显示 Text。

平台包直接运行，无需 Godot 编辑器；需要图形桌面及 Compatibility 驱动。Windows 实机测试按约定在 1.0.0 统一执行。程序未代码签名。

下一功能版本为 **0.0.5：单层条件**。本版授权不延伸至下一版。
