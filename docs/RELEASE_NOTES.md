# PAGE Editor 0.2.0 发布说明

Godot：4.7.1.stable.official.a13da4feb；Dialogic：2.0-alpha-20。

本版提供 Choice、条件选项、Label、Jump、Return、End，以及嵌套、跨时间线跳转和返回。对应属性窗口生成原生源文本，预览使用原插件事件与运行子系统。支持隐藏/禁用/默认行为、禁用文本与字符串附加参数；动态目标按运行值解析。原插件代码与资源内容、主场景与用户维护的根 README 保持原字节；Godot 生成的导入元数据不属于此项字节承诺。

依赖加载、缺失与歧义诊断、当前主缓冲区预览、循环保护和调用栈保护适用于本版流程。变量、表达式、嵌套条件、条件文本及基础角色继续可用。细节和保护边界见 docs/README.md；示例见 examples/flow_story。

下一功能版本为 **0.3.0：角色与立绘**，需要单独确认实施范围和开始编码。完整 Dialogic 功能目标不变。
