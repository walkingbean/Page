# PAGE Editor 0.8.0 发布说明

本版主题为“完整创作交互”，以正式 0.7.0 Source 为工程基线。固定使用 Godot 4.7.1-stable 与 Dialogic 2.0-alpha-20，保留原界面整体布局与主题；根 README 由用户维护，原始字节保持不变。后续范围见 [ROADMAP.md](ROADMAP.md)。

## 本版功能

- Visual / Text 共用同一份原生 `.dtl` 文本和撤销历史。视觉视图显示 23 类原生事件，保留注释、连续行、缩进、翻译 ID 与空白；内部 EndBranch 不显示为可编辑事件。
- 支持多选、复制、剪切、粘贴、复制事件、删除、上下移动、拖动排序、缩进与反缩进。选中分支父事件时按完整子树操作，非法结构拒绝提交；复制出的新事件移除原翻译 ID。
- Properties 支持 Background 自定义场景及固定插件的全部命名转场，场景脚本在独立目标进程运行。属性窗口编辑各事件原生属性，Source… 编辑选中事件完整源码。两种入口都检查过期缓冲区，确认修改可单次撤销。变量赋值支持 `= / += / -= / *= / /=`、标量表达式和标准整数随机范围。
- 查找与替换支持大小写、完整单词、正则表达式、捕获组、选择范围与批量撤销；只读和预览状态禁止替换。
- 补全提供原生事件、角色、立绘、变量及嵌套变量、时间线别名、标签、短码参数和适用资源路径。空行也可通过 Complete / Ctrl+Space 选择模板。
- 从资源侧栏拖入角色、时间线、图片和音频，在当前原生文本中插入相应事件。路径限定于内容根，非法资源或批量输入整体拒绝。
- Play here 从选中事件对应的原生索引启动，使用当前未保存草稿；跳过的前置赋值、入场等事件不会预执行。
- All native Dialogic settings 按类别和名称编辑固定插件原生设置，提供类型校验、重置、未知字段保留、冲突检查及保存/放弃/取消。编辑器字号、换行、空白显示和模式偏好单独保存在本机，不写入内容项目。

## 使用边界

通过 Content Folder 选择可写内容根。编辑器与目标资源根相互独立，保存采用固定 Dialogic 原生格式；未支持或无法安全解析的输入会说明原因并保留原文。Properties 不把任意宿主表达式解释为普通数据。目标项目中的扩展脚本由独立原生预览进程运行，依赖 Godot 编辑器接口的编辑工具仍需要固定版本编辑器。

源码读取上限为 4 MiB。物理行超过 16,384 字符时临时关闭该文档自动换行，完整源码与用户换行偏好保留；视觉列表只截短显示预览。资源扫描上限为 20,000 项及 64 层目录。原生随机整数范围写为 `range(min, max).pick_random()`，上界不包含，限制在 32 位整数与最多 1,000,000 个候选数内。

固定 Dialogic 的原生保存器会裁去整个时间线首尾空白；PAGE 自身原样保存测试与原生语义往返测试分别核对。带翻译 ID 的 TextInput 后接其他事件时，固定原生保存器可能丢失分隔空行，重新打开时把后续内容吸收到 ID；PAGE 保存保留原始分隔，原生往返仍记为未完成。启用加密后首次创建空 global_info.txt，固定原生路径会触发引擎 free_static 的空指针错误；加密数据实际写读已测试，但初始化整项仍未完成。依赖版本保持固定，未修改原始插件来掩盖差异。

C-SET-05 的继承旧断言仍要求拒绝本版 r2 明确支持的复合赋值与规范随机范围；该条失败保留为未运行，未在实现后改写冻结定义。新增操作由 C-EXP-10 和 C-080-PROP-04 分别验证。C-040-RT-06 的继承旧边界要求不运行任何目标脚本，与 0.7 起独立目标进程执行扩展的范围冲突；缺失资源的实际诊断和原字节保留已检查，整项仍记为未运行。

固定 Alpha20 会忽略 simple/full history 的保存开关，两类历史仍被写入和恢复；PAGE 与原始参考工程的四种组合均已复现，C-050-HISTORY-03 保留为未运行。原生 Save 保存器还会把显式 `slot="Default"` 省略为 `[save]`，其自身重开和 PAGE 重开都会得到空槽名；当项目默认槽另有配置时需注意这一语义差异，C-050-REF-01 严格往返保持未运行。其他实际未完成样本见测试摘要。
