# PAGE Editor 0.0.1 发布说明

发布日期：2026-10-23（UTC+8）  
Godot：4.7.1 标准版  
Dialogic：2.0-alpha-20  
平台：Windows x86_64、Linux x86_64

PAGE Editor 是独立对话创作程序。用户解压平台包即可运行，无须打开 Godot 编辑器。Source 提供完整工程与构建工具。本版定位为基础对话创作、基础角色与内容目录管理，完成版本重置。

## 本版功能

- 原生 `.dtl` 新建、打开、文本编辑、保存和另存为；支持旁白、注释和基础角色文本。
- 原生 `.dch` 基础角色编辑：文件名标识、显示名称、名字颜色和单张默认 PNG 立绘。
- 基本 `join` / `leave`，支持 `left`、`center`、`right` 位置及默认进退场行为。
- 内容目录扫描、相对资源路径解析、重复标识与缺失依赖诊断；目录移动后可重新选择内容根。
- Dialogic 运行预览的推进、停止、重启与自然结束。
- 单行字面查找、物理源行诊断及定位，文本控件的撤销与重做。
- 未保存处理、外部修改冲突处理、超范围文件只读保护和保存恢复副本。

项目名称、主窗口、预览标题、页脚、左上角 LOGO、应用图标和交付命名采用 PAGE Editor。`config/branding.cfg` 集中管理产品名称、文件名前缀、LOGO、应用图标和稳定用户数据目录；`VERSION.txt` 管理 `0.0.1`，Windows 数字版本为 `0.0.1.0`。

界面使用指定 UI 的场景、布局和主题，图形与引用作产品配置所需的局部调整。第三方依赖名称、API、格式和许可证保持准确。

## 使用方法

Windows 解压后运行 `PAGE_Editor.exe`。Linux 解压后执行 `./PAGE_Editor.x86_64`；若解压工具未保留执行权限，先执行 `chmod +x PAGE_Editor.x86_64`。应用需要图形桌面和支持 Compatibility 渲染的驱动。

将示例目录复制到可写位置。使用 **Content Folder** 选择 `examples/character_story/`，打开 `conversation.dtl`，再按 **Play / F5**。Enter、Space、Advance 或点击对话区域推进，Esc / F6 / Close 停止。完整说明见 Source 的 README 或平台包的 USER_GUIDE。

## 功能边界

本版未提供变量、表达式、条件、选项与跳转、多立绘、高级角色属性、`UPDATE`、动画与变换、媒体、样式编辑、术语、翻译、自定义扩展和完整视觉事件块编辑。未支持的界面入口保持禁用。超范围内容采用只读保护，不静默删除属性。

查找为单行字面匹配，不含替换、正则或跨行查询。`.dtl` / `.dch` 不超过 4 MiB；PNG 不超过 32 MiB、单边 8192 像素且总像素不超过 1600 万；目录扫描上限为 20000 项和 64 层。这些限制不构成流畅性能保证。

保存前创建 `.editor-backup-` 恢复副本，不保证断电或崩溃时的原子提交。用户内容与应用资源目录分离；文件中的 `res://` 按选定内容根解释。
